# Семейный бюджет

Небольшой сайт для учёта семейных финансов: приветственная страница и рабочий калькулятор доходов, расходов и накоплений.

Данные хранятся только в браузере (`localStorage`). Сервер и база данных не нужны.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `index.html` | Лендинг: описание сервиса и переход к калькулятору |
| `Калькулятор.html` | Рабочий калькулятор бюджета |
| `css/landing.css` | Стили главной страницы |
| `js/theme.js` | Светлая и тёмная тема для обеих страниц |
| `LICENSE` | Лицензия MIT |

## Структура репозитория

Проект статический: HTML, CSS и JavaScript, без сборки и зависимостей.

Если Git установлен, можно инициализировать репозиторий в этой папке:

```bash
git init
git add .
git commit -m "Первый коммит: лендинг и калькулятор семейного бюджета"
```

## Как открыть

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в браузере.
3. Нажмите **Открыть калькулятор**.

Либо сразу откройте `Калькулятор.html`.

Тема переключается кнопкой в правом нижнем углу и запоминается в этом браузере.

## Возможности калькулятора

- Доходы и расходы по месяцам
- Итоги: доход, расход, остаток, норма сбережений
- Анализ категорий и финансовые рекомендации
- Расчёт цели накоплений
- Экспорт месяца в CSV (разделитель `;`, удобно для Excel)
- Светлая и тёмная тема

## Важно

Очистка данных сайта в браузере удалит сохранённый бюджет. Перед этим можно выгрузить месяц в CSV.
